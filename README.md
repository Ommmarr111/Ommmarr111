### What I can build

- REST APIs with Clean Architecture — proper layering, Repository + Unit of Work, not a God-controller
- Auth systems: JWT with refresh token rotation, reuse detection, and role-based access control
- Race-condition-safe writes — knowing when a transaction is enough vs. when you need `Serializable` isolation or an atomic conditional update
- Caching layers — cache-aside pattern with both `IMemoryCache` and Redis, invalidation on writes, not just TTL and hope
- Real-time features with SignalR — live notifications, not just request/response
- Integration + unit tests that actually catch bugs — `WebApplicationFactory`, stubbed auth handlers, isolated test databases
- Reading and contributing to a large open-source codebase, not just my own projects
